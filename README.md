# Matroid Growth

A Python framework for studying binary matroids generated by preferential attachment (PA), their structural phase transitions, and Markov chains on the circuit spaces of quantum error-correcting codes (QECCs).

---

## Overview

Binary matroids are generated column-by-column using a preferential attachment rule: each new column selects k rows with probability proportional to their current usage raised to the power β. This produces a rich family of random binary matroids whose structure depends on two key parameters:

- **β** — attachment bias (β=0: uniform; β→∞: hub-and-spoke)
- **d = n/r** — matroid density (columns per basis element)

The framework studies two lines of investigation:

1. **Phase transitions in the PA matroid** — rank saturation, minor appearance thresholds, and Zipf's law in row usage as functions of β and d.

2. **Markov chain on the circuit space** — an adjacent Metropolis–Hastings chain on the circuits of M[H_X] (the binary matroid of a CSS code's X-parity-check matrix), motivated by the problem of efficiently sampling the circuit space of quantum LDPC codes and approximating the weight enumerator A(z).

```

  fields.py          GF(2) arithmetic
  minors.py          Forbidden minors (F7, W3, U2,4)

analysis/

  circuits.py        Minimal dependent set algorithms
  connectivity.py    k-connectivity tools
  stats.py           Zipf distribution and entropy metrics

experiments/
  phase_transition_v2.py   Rank deficit, Gini coefficient, girth vs β and d
  zipf_plot.py             Zipf's law in row usage across β values
  threshold_phenomena.py   Rank saturation and minor appearance thresholds

markov-circuits/
  markov_chain.py      Chain step, fundamental circuits, GF(2) decomposition
  analysis.py          BFS circuit enumeration, irreducibility check
  stationary.py        Exact transition matrix and stationary distribution
  mixing.py            Spectral gap, TV distance
  toric_code.py        Toric code as binary matroid
  hgp_code.py          Hypergraph product (HGP) codes
  bp_code.py           Bivariate bicycle (balanced product) codes
  fb_code.py           Fiber bundle codes (twisted C_r × C_s complex)
  qt_code.py           Quantum Tanner codes (left-right Cayley complex, PSL(2,p))
  qecc_comparison.py   Chain analysis utilities shared across families
  gap_scaling.py       Full gap scaling sweep — all 6 families
  consolidate.py       Consolidation figure from saved JSON results
  qecc_properties.py   PDF summary: QECC properties and weight enumerator
  gap_scaling_results.json  Compact tabular results (all families)
  fb_params.json       Fiber bundle [[n,k]] parameters
  qt_params.json       Quantum Tanner [[n,k]] parameters
```

## Quickstart

```bash
git clone https://github.com/alp-oz/matroid-growth.git
cd matroid-growth
python -m venv venv && source venv/bin/activate
pip install -e .
```

Run the phase transition and threshold experiments:
```bash
python experiments/phase_transition_v2.py
python experiments/threshold_phenomena.py
python experiments/zipf_plot.py
```

Run the full Markov chain gap scaling study across all CSS code families:
```bash
python markov-circuits/gap_scaling.py      # takes ~20 min, saves results JSON
python markov-circuits/consolidate.py      # regenerates figures from JSON instantly
```

## Key findings

### PA matroids
- Row usage follows a power law (Zipf's law) with exponent s growing with β; sharp transition near β ≈ 1
- Rank saturation and minor appearance both exhibit sharp sigmoid threshold transitions at critical densities d*
- d* shifts left with β: higher attachment bias lowers the threshold density for both phenomena
- start_r threshold r* shifts right with β (r* ≈ 46, 64, 109, 237 for β = 0.7, 1.0, 1.3, 1.6)

### Markov chain on QECC circuit spaces
- The adjacent MH chain on circuits of M[H_X] mixes in **sub-linear time** across all 6 families tested
- Autocorrelation gap estimate δ̂ ~ n^{-α} with **α < 1 for every family** (consistent with poly(n) mixing conjecture)
- Power-law exponents: FB (0.24) < Toric (0.36) < QT/Bicycle (0.46) < BB (0.50) < HGP (0.55)
- Fiber bundle codes mix fastest; non-abelian group structure (PSL(2,5)) does not impede mixing
- The weight enumerator A(z) is #P-hard exactly; poly(n) mixing would make MCMC approximation efficient
