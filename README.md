# Matroid Growth

A Python framework for studying binary matroids generated by preferential attachment (PA), their structural phase transitions, and Markov chains on their circuit spaces — motivated by quantum error-correcting codes (QECCs).

---

## Overview

Binary matroids are generated column-by-column using a preferential attachment rule: each new column selects k rows with probability proportional to their current usage raised to the power β. This produces a rich family of random binary matroids whose structure depends on two key parameters:

- **β** — attachment bias (β=0: uniform; β→∞: hub-and-spoke)
- **d = n/r** — matroid density (columns per basis element)

The framework studies two lines of investigation:

1. **Phase transitions in the PA matroid** — rank saturation, minor appearance thresholds, and Zipf's law in row usage as functions of β and d.

2. **Markov chain on the circuit space** — an adjacent Metropolis–Hastings chain on the circuits of M[H_X] (the binary matroid of a CSS code's parity-check matrix), motivated by the problem of sampling from the circuit space of quantum LDPC codes in polynomial time.

## Structure

```
matroid_core/
  engine.py          PA binary matroid generator
  fields.py          GF(2) arithmetic
  minors.py          Forbidden minors (F7, W3, U2,4)

analysis/
  probe_minors.py    Bitset-based minor detection and rank computation
  circuits.py        Minimal dependent set algorithms
  connectivity.py    k-connectivity tools
  stats.py           Zipf distribution and entropy metrics

experiments/
  phase_transition.py      1D parameter sweep (start_r, β, C)
  phase_transition_v2.py   Improved sweep: rank deficit, Gini, girth
  phase_heatmap.py         2D heatmap over (start_r × β)
  zipf_plot.py             Zipf's law in row usage across β values
  threshold_phenomena.py   Rank saturation and minor appearance thresholds

markov-circuits/
  engine.py            PA matroid generator (markov-circuits variant)
  markov_chain.py      Chain step, fundamental circuits, GF(2) decomposition
  analysis.py          BFS circuit enumeration, irreducibility check
  stationary.py        Exact transition matrix and stationary distribution
  mixing.py            Spectral gap, TV distance
  toric_code.py        Toric code as binary matroid
  hgp_code.py          Hypergraph product codes
  qecc_comparison.py   Chain comparison across QECC families
  gap_scaling.py       Spectral gap scaling study (coupling + autocorrelation)
  proposal_summary.py  Publication-quality evidence figure for poly(n) mixing
```

## Quickstart

```bash
git clone https://github.com/alp-oz/matroid-growth.git
cd matroid-growth
python -m venv venv && source venv/bin/activate
pip install -e .
```

This installs the package (`matroid_core`, `analysis`, `experiments`) and registers the `run-matroid` CLI entry point.

Run the full batch simulation:
```bash
run-matroid
```

Run the phase transition experiment:
```bash
python experiments/phase_transition_v2.py
```

Run the threshold phenomena study:
```bash
python experiments/threshold_phenomena.py
```

Run the Markov chain gap scaling study (takes a few minutes):
```bash
python markov-circuits/gap_scaling.py
```

## Key findings

### PA matroids
- Row usage follows a power law (Zipf's law) with exponent controlled by β
- Rank saturation and minor appearance both exhibit sharp threshold transitions at critical densities d*
- d* shifts with β: higher attachment bias lowers the threshold density for both phenomena

### Markov chain on QECC circuit spaces
- The adjacent MH chain on circuits of M[H_X] appears to mix in **poly(n)** steps across bicycle, toric, and hypergraph product code families
- Coupling time scales as O(n^α) with α ≈ 1.8–2.7 (not exponential in N, the circuit count)
- Spectral gap stays bounded away from 0 for all tested instances
- gap = 0 is a fast rejection criterion for codes with minimum distance d = 2
